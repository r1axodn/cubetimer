# 큐브 타이머 (Cube Timer)

스피드큐빙을 위한 브라우저 타이머. 설치 없이 열면 바로 쓸 수 있고, 기록은 브라우저(localStorage)에 저장됩니다. 이메일로 로그인하면 같은 기록이 Supabase에 자동 백업되어 다른 기기에서도 이어서 쓸 수 있습니다.

**바로 쓰기 → https://r1axodn.github.io/cubetimer/**

## 기능

### 타이머
- **PC**: 스페이스바를 0.5초 이상 누르면 준비(초록색), 떼면 측정 시작, 측정 중에는 아무 키나 누르면 정지
- **모바일**: 타이머 영역을 0.5초 이상 누르면 준비, 떼면 시작, 측정 중에는 화면 어디를 눌러도 정지
- **15초 인스펙션** 모드: 8초·12초 경고(색상 + 선택적 비프음), 15초 초과 시 자동 +2, 17초 초과 시 자동 DNF
- 0.01초 / 0.001초 표시 정밀도 선택
- 측정 중에는 다른 UI가 흐려지는 집중 모드

### 스크램블 & 전개도
- 종목: 3x3x3(20수), 2x2x2(9~11수), 4x4x4(40수, 와이드 무브 포함), Pyraminx(11수 + 팁)
- WCA 방식 난수 생성 — 같은 면 연속 금지, `R L R` 같은 마주보는 면 반복 방지
- 이전 / 다음 스크램블 이동, 스크램블 클릭 시 복사
- 2x2x2 · 3x3x3 · 4x4x4는 스크램블을 적용한 **6면 2D 전개도**를 실시간 표시 (스크램블 검증용)

### 클라우드 백업 (선택)
- 헤더의 **로그인 / 백업** 버튼에서 이메일 + 비밀번호로 회원가입 / 로그인 (Supabase Auth)
- 회원가입 후 인증 메일이 오면 링크를 누르고 로그인
- 로그인하면 헤더에 이메일(짧게)과 동기화 상태(`동기화됨` · `저장 중…` · `오프라인` · `DB 설정 필요`)가 표시되고, 클릭하면 **지금 백업** / **로그아웃** 메뉴가 열립니다
- 기록 변경(솔브 추가, +2 / DNF / 삭제, 세션 변경)은 localStorage에 즉시 저장되고, 로그인 상태에서는 2.5초 디바운스로 서버에 upsert 됩니다 (사용자당 1행)
- 로그인 직후 서버 사본을 읽어 솔빙을 `id` 기준으로 병합합니다 (`id` 중복 제거, 시각순 정렬). 한쪽이 비어 있으면 있는 쪽을 그대로 사용
- 로그인하지 않았거나 CDN/네트워크가 없어도 타이머·기록은 평소처럼 로컬에서 동작합니다

**준비물**: Supabase 프로젝트에서 [`supabase/user_backups.sql`](supabase/user_backups.sql)을 SQL Editor로 한 번 실행하세요. 테이블이 없으면 앱은 `DB 설정 필요` 상태만 표시하고 기록은 로컬에 계속 저장합니다.

### 기록 관리
- 세션: 추가 / 이름 변경 / 초기화 / 삭제, 종목별로 자동 저장
- 직전 기록과 목록의 각 항목에서 바로 `+2` / `DNF` / `삭제`
- 기록을 누르면 시간·페널티·스크램블·시각 상세 보기
- **단일 최고 기록(PB) 경신 축하**: 방금 기록이 이전 세션 최고 기록보다 빠르면(인스펙션 +2 반영, DNF 제외) `NEW PR!` 배지와 단축 폭(`-0.84s`), 경량 컨페티가 약 2.8초간 표시됩니다. 세션 첫 기록이나 Ao5/Ao12 갱신에는 나오지 않습니다.
- CSV / JSON 내보내기

### 통계
- 최근, 최고(PB), 평균 5 / 12 (현재·최고), 평균 50 / 100, 세션 평균, 솔브 수(완료/전체)
- 절사평균: 평균 5·12는 최고·최저 1개씩 제외, 평균 50·100은 상·하위 5%(3개·5개)씩 제외, 허용 개수를 넘는 DNF는 평균 DNF
- 최근 기록 추이 그래프(SVG)와 목표 기록 기준선

### UI
- 다크 / 라이트 테마 전환
- 한국어 UI, iPhone·데스크톱 반응형

## 구조

```
index.html          마크업
assets/style.css    테마와 레이아웃
assets/cube.js      큐브 면 조각 모델 (2x2x2 / 3x3x3 / 4x4x4)
assets/scramble.js  WCA 방식 스크램블 생성·파싱
assets/stats.js     절사평균 등 통계 계산
assets/cloud.js     Supabase 로그인 · 클라우드 백업/병합
assets/app.js       타이머 상태 머신, 기록 저장, 렌더링
supabase/user_backups.sql  백업 테이블 + RLS 정책 SQL
```

빌드 도구 없이 정적 파일만으로 동작하며, 저장소 루트를 GitHub Pages로 제공합니다.

## 로컬에서 열기

`index.html`을 브라우저로 열거나, 임의의 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000
```

## 키보드

| 키 | 동작 |
| --- | --- |
| `Space` (0.5초 이상) | 준비 → 떼면 시작 / 측정 중 아무 키로 정지 |
| `Esc` | 준비·인스펙션 취소 |
| `←` `→` | 이전 / 다음 스크램블 |
